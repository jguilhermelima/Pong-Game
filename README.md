<h1 align="center"> Ping Pong </h1>

<h2>Descrição do Projeto</h2>
Este projeto é uma recriação do jogo de ping pong estilo arcade.

Toda a aplicação é feita utilizando o modulo do Python Turtle graphics.

Uso:
Utilizar teclas "w", "s" para controla a barra de esquerda e "↑", "↓" para controlar barra de direita

<h2>🛠️ Construído com</h2>

* Python

* Pillow
